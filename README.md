# Kathy_LSC

Leesmateriaal en oefentools voor leerlingen. Elke tool staat in een eigen map en werkt zonder installatie, offline, op computer, chromebook en tablet.

Startpagina: https://sergehanssens.github.io/Kathy_LSC/
